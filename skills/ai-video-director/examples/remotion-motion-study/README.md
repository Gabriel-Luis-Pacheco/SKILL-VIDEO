# Exemplo Remotion: uma ideia ganha forma

**Status:** código de referência original, **ainda não compilado/renderizado neste repositório**. O CI verifica Python e estrutura; não instala dependências JS nem revisa design subjetivo.

O exemplo é frame-determinístico e usa um objeto que chega, uma ligação que se cria e uma ideia que emerge: abertura → transformação → resolução. Sem preset de gradientes, particles, whooshes e paredes de texto.

1. Criar projeto de Remotion conforme documentação oficial: https://www.remotion.dev/docs/
2. Copiar Video.tsx e Root.tsx para o src do projeto e registrar RemotionRoot no entrypoint.
3. Visualizar composição VideoOSMotionStudy no Studio. Duração 210 frames/30fps, vertical 1080x1920.
4. Renderizar e inspecionar os frames 0, 44, 118, 150, 205, além de todo o movimento contínuo.
5. Adicionar som/licenças e exportar o master; revisar metadados com o video_qc.py e a estética com pessoa.
6. Mudar tipografia/forma para identidade real antes de usá-lo comercialmente.

**Não equivale a prova artística de mercado.** Qualidade de som, legibilidade de fonte instalada, fidelidade de marca, performance e export exigem teste efetivo.
